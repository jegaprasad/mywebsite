thejpcinema - upload steps
1. Edit config.js: set NEXTCLOUD_URL to your Nextcloud address.
2. Copy your poster images into the posters folder.
3. Upload everything in this folder to your hosting web root (public_html).
4. In Nextcloud, install the "WebAppPassword" app and add your site address
   (https://thejpcinema.xyz) to its allowed origins.
